# Support

## How to get help

| Need | Channel |
|------|---------|
| 🐛 Bug report | [GitHub Issues](../../issues/new?template=bug_report.md) |
| ♿ Accessibility issue | [GitHub Issues — a11y template](../../issues/new?template=a11y.md) (P0, fast-tracked) |
| ✨ Feature request | [GitHub Issues — feature template](../../issues/new?template=feature_request.md) |
| 💬 Question / discussion | [GitHub Discussions](../../discussions) |
| 🔒 Security vulnerability | See [SECURITY.md](SECURITY.md) — do not file a public issue |
| 📦 Commercial / consulting | Reach out via the email in `package.json` |

## Before opening an issue

1. Search [existing issues](../../issues?q=is%3Aissue) — yours might already be tracked.
2. Verify against the latest `1.x` release.
3. Provide a minimal reproduction (CodeSandbox / StackBlitz preferred).
4. Include browser + OS, theme mode, and any custom neutral hex.

## Response times (best effort)

- 🐛 Bug reports: ~7 days
- ♿ Accessibility issues: ~48 hours (P0)
- ✨ Feature requests: triaged monthly
- 💬 Discussions: as the community responds
